# Blender / Unity Model Checklist

## Blender
- [ ] Only one real armature exists.
- [ ] Body mesh uses the correct armature.
- [ ] Clothing mesh is parented to the same armature.
- [ ] Clothing uses transferred weights.
- [ ] Pose Mode test works.
- [ ] Clothing does not fly away.
- [ ] Hidden body parts under clothing are removed.
- [ ] Final FBX exported with selected objects only.

## Unity Import
- [ ] FBX imports correctly.
- [ ] Humanoid avatar is valid.
- [ ] Required bones are green.
- [ ] Scale is acceptable.
- [ ] Model faces correct direction.
- [ ] Body and clothing visible.
- [ ] Animation uses Copy From Other Avatar.
- [ ] Idle loops.
- [ ] Attack/hit/death clips do not loop.
- [ ] Root motion is OFF.
