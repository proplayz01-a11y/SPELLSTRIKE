# SPELLSTRIKE Codex Skill Pack

Drop this folder into your project docs or copy the important files into your repo root.

Recommended use:
1. Put `AGENTS.md` in the root of the SPELLSTRIKE Unity repository.
2. Put the `docs/`, `prompts/`, and `checklists/` folders somewhere like `docs/codex/`.
3. In Codex, start with:

```txt
Read AGENTS.md and docs/codex before editing. Follow the SPELLSTRIKE workflow.
```

Main purpose:
- Keep Codex aligned with SPELLSTRIKE's architecture.
- Prevent random rewrites of working Unity systems.
- Preserve layer-by-layer development.
- Give Codex reusable prompts for enemies, debuffs, UI, bosses, Blender-to-Unity model setup, and testing.

This pack was generated from the uploaded SPELLSTRIKE manuscript, handoffs, debuff system plan, Corsair Phantom handoff, Blender workflow, and full chat handoff.
