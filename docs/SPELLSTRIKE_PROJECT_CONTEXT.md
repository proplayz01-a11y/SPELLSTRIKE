# SPELLSTRIKE Project Context

## Core Concept

SPELLSTRIKE is a 3D arena-based word-combat game where players form words under pressure to cast attacks, survive enemy mechanics, and progress through story-driven stages.

Core gameplay loop:

1. Enter arena.
2. Avoid enemy attacks using movement.
3. Collect or use letter tiles.
4. Form valid English words.
5. Cast attacks by submitting words.
6. Defeat enemies or bosses.
7. Obtain soul fragments and rewards.
8. Progress to the next node or stage.

## Educational Direction

SPELLSTRIKE supports:
- vocabulary reinforcement
- fast word recognition
- spelling accuracy
- cognitive pressure handling
- language enhancement
- strategic decision-making

The core educational mechanic is active word retrieval under combat pressure.

## Story Summary

Van Aert is a wizard who enters a living spellbook-prison to recover the soul fragments of his daughter Nevali.

Soul fragment progression:
- Stage 1 = Voice
- Stage 2 = Memories
- Stage 3 = Emotions
- Stage 4 = Identity
- Stage 5 = Soul

Vander Poel / Master Wizard and Broken Language are central antagonistic forces.

## Stage Progression Philosophy

```text
Stage 1 = Learning
Stage 2 = Pressure
Stage 3 = Complexity
Stage 4 = Mastery
Stage 5 = Identity / Soul Collapse
```

## Combat Philosophy

The game should feel:
- fast
- pressuring
- reactive
- educational under stress

It should not feel like:
- static typing
- passive puzzle gameplay
- slow classroom drills wearing a wizard hat
