# Validation evidence and gates

PASS means actual Unity or source evidence. External Blender 14/14 and GLB 33/33 and 1212 bridge support samples are provenance, not Unity traversal or Titan QA. The main GLB contains 281090 triangles; LOD1 contains 199754 triangles (28.94 percent reduction); collision 19 meshes/3816 triangles. Do not render both visual exports at once. URP ORM R=occlusion G=roughness B=metallic; avoid treating it as Unity metallic/smoothness texture. Water, foam, portal and glows need independent Unity shader/VFX passes.

Runtime Play Mode is blocked until save isolation is proven. Never clear PlayerPrefs or modify the authoritative JSON save.
